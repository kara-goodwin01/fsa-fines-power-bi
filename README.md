# fsa-fines-power-bi
# Federal Student Aid Fines Analysis — Power BI Dashboard

## Overview

This Power BI dashboard analyzes fines imposed by Federal Student Aid (FSA)
on postsecondary institutions across multiple fiscal years.

The report was designed to make it easier to explore how fines vary by year,
institution, geography, violation type, and institution type.

## Tools

- Power BI

- Data Visualization
- Data Cleaning and Transformation
- Interactive Dashboard Design

## Dashboard Features

The dashboard allows users to explore:

- Total dollar value of fines imposed
- Number of fines by fiscal year
- Fine amounts by institution
- Fine amounts by violation/reason
- Geographic distribution of fined institutions
- Distribution of fines by university type
- Fiscal-year filtering

## Report Pages

### Dashboard

The main dashboard provides an interactive overview of Federal Student Aid fines,
including KPI metrics, geographic analysis, institution-level detail,
fine categories, and fiscal-year trends.

### Definitions

A definitions page provides additional context for the fine categories represented
in the dataset, including Campus Security / Clery Act fines, Drug-Free Schools
and Communities Act fines, IPEDS fines, Qui Tam cases, and other violations.

## Power BI File

The original Power BI project file is included in this repository:

`FSA-Fines-Dashboard.pbix`

## Data Source

Federal Student Aid / U.S. Department of Education

## Project Purpose

This project demonstrates the use of Power BI to transform regulatory and
institution-level data into an interactive analytical dashboard that supports
comparison across time, geography, institutions, and violation categories.
